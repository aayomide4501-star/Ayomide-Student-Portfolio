# COS 106 Portfolio - VS Code Setup

## Files
index.html, about.html, projects.html, planner.html, contact.html, style.css, script.js

## Run locally
1. Install VS Code + Live Server extension
2. Open this folder in VS Code
3. Right-click index.html > Open with Live Server

## Personalise
Replace 'Abimbola Lutifulahi Ayomide', photo URL, school, projects.

## Go live (free)
Option A - Netlify Drop: drag this folder to app.netlify.com/drop
Option B - GitHub Pages: push to GitHub > Settings > Pages > Deploy from branch > main / root
Option C - Vercel: import GitHub repo at vercel.com

Submit the live link + GitHub link to your lecturer.
